Week 1 — Day 1

On the first day of my internship at Tinkerer's Lab, I was introduced to GitHub and VS Code. I created my first repository and pushed it to the remote repository through VS Code.

I installed VS Code, familiarized myself with it, and logged into my GitHub account.

What is GitHub?

GitHub is a website where you can store and share your code online — think of it like Google Drive, but made for developers. It is a web-based platform used for version control and collaborative software development using Git. It allows developers to host repositories, track changes, and collaborate with others.

Start by creating a new repository — go to your GitHub account and click the "New" button.

Give your repository a name and a description.

Turn on "Initialize this repository with a Readme."

What is a README? A README file provides information about a project — its purpose, how to use it, and other relevant details. It is the first thing users see when they visit a repository.

Your repository is now created with the README file in it.

Now we will clone this repository to our local machine using VS Code.

Create a new folder on your local machine and open it in VS Code.

Click on the three dots → Terminal → New Terminal. You can now see the path of your folder in the terminal.

Now push the repository to GitHub using these commands:

// click on any command to learn more

01 git init Initializes a new Git repository ▼
This command creates a hidden .git folder inside your project folder. That folder is what makes it a Git repository. You only run this once at the start of a new project. Without this, Git has no idea your folder exists.
02 git add . Stages all files for commit ▼
The dot ( . ) means "add everything". This command tells Git which files you want to include in your next save. Think of it like selecting files before copying them. Without this step, Git won't include your changes in the commit.
03 git commit -m "first commit" Saves a snapshot of your files ▼
This saves your staged files as a snapshot in Git history. The -m flag lets you add a message describing what you changed. Every commit is like a save point — you can always go back to it. The message helps you remember what you did.
04 git branch -M main Renames the branch to main ▼
By default Git creates a branch called "master". GitHub now uses "main" as the standard name. This command renames your branch to "main" so it matches GitHub's default and everything syncs properly.
05 git remote add origin <URL> Links your local repo to GitHub ▼
This connects your local project folder to your GitHub repository online. The word "origin" is just a nickname for the URL of your GitHub repo. You replace <URL> with the actual link from your GitHub repository page.
06 git push -u origin main Uploads your code to GitHub ▼
This uploads all your committed files to GitHub. The -u flag sets "origin main" as the default so next time you can just type git push without the extra words. After this your code is live on GitHub!

Your repository is now pushed to GitHub. Open your GitHub repository.

Click on Settings.

Click on Pages.

Click on "Visit Site" to see your website live in the browser.

Your website is now published! As you update the code and push, changes will reflect on the live site.

Day 2 — Inkscape & Fusion 360

On the second day we were taught about two software tools: Inkscape and Autodesk Fusion 360.

Inkscape is a free and open-source vector graphics editor used for creating SVG files. It provides tools for designing logos, labels, diagrams, and illustrations.

Why Inkscape?

In our internship we focus on Product Development, IoT, Robotics and Embedded Systems. For product development we need to design logos, labels, enclosures and diagrams. Inkscape is a free vector design tool that helps us do all of that. It also exports SVG files directly used in laser cutting and CNC machines — very common in Tinkerers' Lab. Overall Inkscape is a very useful tool for anyone in a hands-on product development environment.

Types of Images

1) Raster Images — Made of pixels. Lose quality when resized. Formats: JPEG, PNG, GIF.

2) Vector Images — Made of mathematical equations. Scale infinitely without losing quality. Formats: SVG, AI, EPS.

3D Printers at Tinkerers' Lab

In our lab we use Bambu Lab 3D printers — the A1, A1 Mini, P1S and H2D. Each one has its own specialty. The A1 and A1 Mini are great for everyday small parts. The P1S is fast and enclosed for different materials. The H2D supports dual extrusion meaning it can print with two materials at once. These printers help us prototype parts for our robotics and product development projects.

Filaments

We use different types of filaments including PLA, ABS, PETG and TPU. PLA is easy to print and biodegradable — great for general use. ABS is stronger and more heat-resistant — ideal for functional parts. PETG combines strength and flexibility. TPU is flexible — used for parts that need to bend or stretch.
